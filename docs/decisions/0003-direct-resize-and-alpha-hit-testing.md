# ADR-0003：无设置界面的直接缩放与逐像素命中

## 状态

Accepted

## 日期

2026-07-11

## 背景

ADR-0002 删除了 settings 页面及其通用配置能力，也一并删除了桌宠右下角缩放把手。实际使用中，设置界面仍然不需要，但直接拖拽调整角色大小属于桌宠本体交互，应独立保留。

透明穿透同时存在粗粒度抢占：主进程使用所有动画帧 alpha 并集的外接矩形唤醒窗口，这个矩形大于当前帧角色像素，导致角色周围较大透明区域无法点击后方窗口。

## 决策

- 不恢复 settings 页面、settings 菜单、透明度或置顶配置。
- 在角色右下角恢复独立缩放把手，允许 84–228px、每档 12px 的直接拖拽缩放。
- 仅持久化 `selectedPetId` 与 `mascotWidthPx`，继续复用旧文件名完成迁移。
- 主进程只在鼠标离开透明窗口或拖拽期间管理 passthrough；窗口内部交给 renderer 按当前动画帧 alpha 像素和真实控件判断。

## 结果

- 用户无需打开管理界面即可调整桌宠大小，重启后尺寸保持。
- 角色矩形内的透明像素不再被跨帧外接矩形抢占，后方窗口可以接收点击。
- resize IPC 仅允许 `PetWindow` 调用，`ControlWindow` 仍无法访问。

## 验证要求

- picker-only 契约继续拒绝所有 settings surface 与 settings IPC。
- Electron smoke 验证缩放 API、把手 DOM、尺寸状态和重启持久化。
- 几何测试保证窗口内部返回 renderer 判定，窗口外恢复 passthrough，拖拽期间保持 interactive。
- 人工验证角色可见像素可拖拽、把手可缩放、角色周围透明像素可点击后方窗口。
