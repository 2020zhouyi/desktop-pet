# ADR-0004：统一可写用户宠物库

## 状态

Accepted

发布包内种子的具体迁移方式已由 [ADR-0006](0006-consumable-packaged-pet-seed.md) 修订：正常可写环境优先移动，不再固定复制一份。

## 日期

2026-07-11

## 背景

打包后的仓库 `pets/` 位于应用资源或 `app.asar` 中，不适合作为玩家手动增删的目录。Codex 自定义宠物、网站下载宠物和应用内置宠物虽然使用同一资源协议，却分散在不同路径，普通玩家难以管理。

## 决策

- 仓库 `pets/` 仅作为安装包内置种子。
- 首次运行把内置种子迁移到 Electron `userData/pets/`，并写入一次性初始化标记；移动失败时回退复制。
- 运行时只扫描 `userData/pets/`。
- 选择器“管理宠物”直接打开该目录。
- 用户通过文件管理器复制或删除完整宠物文件夹。
- 回到选择窗口时重新扫描资源。
- 运行时 ID 使用 `user:<manifest.id>`，不依赖文件夹名称。
- 文件夹根据 `displayName` 整理为角色名称；非法文件名字符会替换，同名冲突不覆盖。
- 每个角色的 `bubbleLines` 位于自己的 `pet.json`，优先于源码回退。

## 结果

- 内置和自定义宠物使用同一管理路径。
- 应用升级不会要求写入安装包。
- 用户删除内置宠物后不会在每次重启时自动恢复。
- 重命名文件夹或角色名称不会破坏已保存的稳定选择 ID。

## 验证

- `test:pet-library` 验证首次复制、删除不回填、目录命名和旧 ID 迁移。
- Electron smoke 在临时 userData 中验证 30 个内置种子和一个自定义宠物同时可见。
- `pet-health` 验证项目种子和实际用户目录均满足 manifest 与资源边界。
