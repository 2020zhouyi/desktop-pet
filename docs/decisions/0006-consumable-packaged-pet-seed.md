# ADR-0006：发布包内含可消费的宠物种子

## 状态

Accepted

## 日期

2026-07-13

## 背景

桌宠需要在没有网络时包含全部角色，同时让内置角色和玩家角色都能在一个普通文件夹里手动增删。如果把角色永久保留在应用包内，再复制到用户目录，会造成重复占用；如果完全不随包发布，首次启动又依赖网络。

## 决策

- Mac DMG 和 Windows 便携 ZIP 都携带完整 `resources/pets-seed/`。
- `app.asar` 不再包含角色资源。
- 打包态首次运行优先把每个种子角色移动到 `userData/pets/`；跨卷、权限或只读来源下回退为复制，并尽力删除源目录。
- 已存在的同名用户目录永不覆盖。
- 完成初始化后写入 `.bundled-pets-seeded-v1.json`；以后即使玩家删除角色，也不再从发布包恢复。
- 运行时只扫描统一用户目录，“管理宠物”直接打开它。

## 取舍

- 正常从可写的应用目录启动时，迁移后只有用户目录中的一份角色资源。
- 如果直接从只读 DMG 启动，源资源无法删除，会暂时保留在只读镜像中；复制到 Applications 后再次启动会按标记尽力清理应用内种子。
- 当前 Mac 应用未签名。未来启用代码签名后，不应修改签名后的 `.app` 内容；届时需要改为安装阶段解包资源，或接受发布包与用户目录各一份。

## 验证

- `test:pet-library` 覆盖首次迁移、已有目录保护和删除不恢复。
- `package:check` 验证 Electron Builder 的 `extraResources` 映射。
- `package:verify` 验证两个平台成品的种子完整性，并禁止角色重复进入 `app.asar`。
